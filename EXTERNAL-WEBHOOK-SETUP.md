## Option 1: Development Setup with ngrok

### Install ngrok
```bash
# Download from https://ngrok.com/download
# Or use package manager:
winget install ngrok.ngrok  # Windows
brew install ngrok/ngrok/ngrok  # macOS
```

### Setup ngrok tunnel
```bash
# Create tunnel for webhook service (port 3008)
ngrok http 3008

# This will output something like:
# Forwarding: https://abc123.ngrok.io -> http://localhost:3008
```

### Configure GitHub webhook
1. Go to your GitHub repository: `https://github.com/levilonic/Lonic-Flex-Claude-system`
2. Settings → Webhooks → Add webhook
3. **Payload URL**: `https://your-ngrok-url.ngrok.io/webhook/github`
4. **Content type**: `application/json`
5. **Secret**: Generate a secure secret and add to `.env`
6. **Events**: Select "Push", "Issues", "Issue comments", "Pull requests"

### Environment setup
```bash
# Add to .env file:
GITHUB_WEBHOOK_SECRET=your-secure-secret-here
EXTERNAL_WEBHOOK_URL=https://your-ngrok-url.ngrok.io
```

## Option 2: Production Cloud Deployment

### Deploy to Cloud Provider
- **AWS**: Use EC2 with Elastic IP + ALB
- **Google Cloud**: Use Compute Engine + Load Balancer
- **Azure**: Use VM + Application Gateway
- **DigitalOcean**: Use Droplet + Load Balancer

### DNS Setup
```bash
# Point domain to cloud instance
webhooks.your-domain.com → Cloud Instance IP

# GitHub webhook URL becomes:
https://webhooks.your-domain.com/webhook/github
```

### SSL Certificate
```bash
# Use Let's Encrypt with certbot:
sudo apt install certbot
sudo certbot --nginx -d webhooks.your-domain.com
```

## Webhook Endpoints Available

### GitHub Webhooks
- **URL**: `https://your-external-url/webhook/github`
- **Method**: POST
- **Authentication**: HMAC SHA-256 signature verification
- **Events Handled**: push, issues, issue_comment, pull_request

### Manual Testing
- **URL**: `https://your-external-url/chain/trigger`
- **Method**: POST
- **Body**: `{"type": "manual", "command": "health-check"}`

### Health Check
- **URL**: `https://your-external-url/health`
- **Method**: GET
- **Response**: Service status and statistics
